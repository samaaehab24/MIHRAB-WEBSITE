# MIHRAB

MIHRAB is a fashion e-commerce website featuring product display, user login/signup, shopping cart functionality, and detailed product pages.

## Features

- Organized and attractive product display.
- User authentication: login and signup.
- Add products to the shopping cart and view cart contents.
- Detailed pages for each product.
- Responsive design that works on all devices.

## Project Structure

- `index.html`: Main homepage.
- `style.css`: Main stylesheet.
- `script.js`: Main JavaScript file.
- `addtocart1/`, `addtocart2/`, `addtocart3/`: Folders containing different shopping cart pages and functionality.
- `login/`: Folder containing login pages.
- `signup/`: Folder containing signup pages.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Use

1. Open `index.html` in a web browser.
2. Use the navigation links to browse different pages.
3. To modify the project, edit the corresponding files inside the folders.

## Deployment

The website can be published using GitHub Pages by enabling the service in the repository settings and selecting the main branch and root folder.
